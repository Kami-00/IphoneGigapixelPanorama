Hier Hugin.app mit align_image_stack unter Contents/MacOS ablegen.
Hugin ist eine separat zu installierende Abhängigkeit; keine fremden Binärdateien im Repository.
Verwendeter Apple-Silicon-Build: https://github.com/dannephoto/hugin/releases/tag/hugin
Projekt und Quellcode: https://hugin.sourceforge.io/
Zusätzlich benötigt: ImageMagick (brew install imagemagick).
Vorbild: Isaac Ullah (2017), https://isaacullah.github.io/Script-for-creating-superresoultion-images-from-handheld-shots/
Verwandtes Skript: https://github.com/luator/sr_stack (Felix Widmaier, MIT).
Die enthaltene Pipeline ist eine eigene Umsetzung desselben Grundablaufs.
